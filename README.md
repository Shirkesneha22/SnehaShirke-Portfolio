# Sneha Shirke Portfolio

A modern, static portfolio built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Building for Production

This project is configured for static export. To build the project, run:

```bash
npm run build
```

The static files will be generated in the `out` directory. You can serve this directory using any static file server, for example:

```bash
npx serve out
```

## Legacy Code

The original React (CRA) codebase has been preserved in the `/legacy` folder for reference.

## Technologies Used

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Vercel/Netlify for deployment
